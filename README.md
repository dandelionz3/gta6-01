Solmar Bay is an open-world crime game in the spirit of GTA 6, playable in a desktop browser from static files. You are Rook, a small-time driver drawn back into the city's underworld: drive and steal cars across a sun-soaked coastal city, outrun the police as your wanted level climbs, and run a five-mission story chain — from your first stolen wheels to the big armoured-van score — with traffic, pedestrians, combat, a live minimap and procedural sound throughout.

## Run it

```sh
node serve.ts
```

then open http://localhost:8080

## Controls

| Key | Action |
| --- | --- |
| WASD | Move / drive |
| Shift | Sprint |
| Space | Jump (on foot) / handbrake (driving) |
| E | Enter / exit car |
| F | Punch |
| Mouse click | Shoot pistol |
| Mouse drag | Orbit camera |
| M | Mission menu |
| Esc | Pause |
| P | Mute |
